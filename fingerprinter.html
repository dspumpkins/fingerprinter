Fingerprinter

Paste a draft or policy below to get its fingerprint. If the text already carries a fingerprint, this checks whether it still matches. Everything runs in this page — nothing is uploaded anywhere.

There are scenarios where changed text will not produce a different fingerprint. What a fingerprint does not cover

0 characters
For a document going to a vote, use Google Docs → File → Download → Plain text (.txt) and drop that file in, rather than copy-pasting. Copy-paste can silently drop footnotes and tables, which changes the fingerprint. Copy-paste is fine while you’re still drafting.

What a fingerprint does not cover

List numbering is stripped before hashing, so these two documents have the same fingerprint:

1. Socks must be worn at all times. 2. Sessions are capped at fifteen minutes. 3. Exceeding item 2 forfeits next week.
=
2. Socks must be worn at all times. 1. Sessions are capped at fifteen minutes. 3. Exceeding item 2 forfeits next week.

Item 3 now penalizes bare feet rather than long sessions, and the fingerprint cannot tell. The same blind spot covers table rows and columns, and a leading initial (J. Chen and K. Chen are identical to it). A fingerprint attests to the words and their order — check numbering, tables, and names by reading.
